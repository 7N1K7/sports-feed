# Kickoff Kiwi

What's on today and this week for New Zealand teams (All Blacks, Black Ferns, NPC, Super Rugby, Black Caps, White Ferns, domestic cricket, Kiwis, Kiwi Ferns, Warriors, Black Sticks hockey), with NZ and local start times, where to watch, results with spoiler hiding, and news.

- `index.html` is the whole site. It reads `data/feed.json`.
- `scripts/fetch.mjs` builds `data/feed.json` every 10 minutes from Wikipedia season pages (fixtures and results, listed in `data/wiki-pages.json`), TheSportsDB's free API (A-League, NRL and Super Rugby rounds, UFC, team logos), and the hand-kept files in `data/curated/` and `data/broadcast.json`. RNZ's sport RSS is off (`RNZ_ON` in `scripts/fetch.mjs`): its terms don't allow posting it on a website without RNZ's permission. Cricket's live state of play (rain delays, lunch, stumps) and score come from Sportmonks' licensed cricket API for T20 internationals and the Big Bash when the `SPORTMONKS_TOKEN` secret is set (free plan), and otherwise from Wikipedia's match boxes. ESPN's score-strip feed (`ESPN_ON`) is off: ESPN's terms don't allow automated access without permission. News headlines come from the NZ Herald (headlines only, under its RSS licence), Scoop, MMA Fighting / MMA Mania / Bad Left Hook, and BBC Sport (its terms, section 15, allow its feeds on a website unchanged and credited with a link); a BBC Sport or Herald cricket headline about rain is also shown on that match's live card. Fighter and team links (Wikipedia, official sites, UFC.com, Sherdog, BoxRec, Tapology) come from Wikipedia and Wikidata. Images are only ever freely licensed (Wikimedia Commons, Openverse) or TheSportsDB's. The other sources in use allow automated use; Wikipedia content is CC BY-SA and is credited in the page footer.
- `.github/workflows/update.yml` runs the fetcher every 10 minutes and publishes to GitHub Pages.

To follow a new competition, add its Wikipedia page to `data/wiki-pages.json`. To add a fixture none of the sources carry, add it to a file in `data/curated/`. To change where-to-watch defaults, edit `data/broadcast.json`.
